# NavalDocs Pro — Release Notes

## v1.0.0-RC1 — "Piloto Controlado"

- **Versão:** 1.0.0-RC1
- **Canal:** Release Candidate
- **Data:** 2026-07-26
- **Escopo:** piloto controlado com empresas reais, antes da versão oficial 1.0

### Principais melhorias

- Wizard de criação de processos 2.0 (onboarding orientado por documentos).
- Pipeline real de OCR com sessões persistentes (`wizard_sessions`) e detecção de duplicidade de cliente/embarcação.
- Smart Process Analyzer: score de qualidade, classificação de risco e probabilidade de aprovação (`process_analyses`).
- Action Engine com registro dinâmico, idempotência atômica e auditoria persistente (`ai_action_audits`, `ai_idempotency_records`).
- Process Workspace 3.0 com Copilot lateral e layout de três colunas.
- Observabilidade RC1: modo piloto, telemetria por operação com `correlation_id`, monitor global de erros e dashboard operacional.

### Correções

- GRANTs de Data API ausentes em 26 tabelas do core (bloqueador P0).
- Persistência real do Action Engine (remoção de mocks — bloqueador P1).
- Propagação de erros no `ActionExecutor` (falhas não mais silenciosas).
- Sobreposição do FAB do Copilot e do botão de feedback com a navegação mobile.

### Mudanças de arquitetura

- Enterprise AI Core: planner dinâmico, sessões de execução, intent interpreter e memória de conversa.
- Criação de processos centralizada em `ProcessCreationService`.
- Idempotência atômica via RPC `claim_ai_idempotency_record`.
- Camada única de observabilidade: `src/lib/pilot-mode.ts`, `src/lib/observability/operations.ts`, `src/lib/observability/error-monitor.ts`.

### Problemas conhecidos

- Avisos informativos do linter de banco sobre funções `SECURITY DEFINER` intencionais (portal público de assinatura).
- Métricas do dashboard consideram as últimas 1000 operações monitoradas.
- Incidentes são registrados manualmente (sem detecção automática).

### Limitações

- Uso restrito a um grupo controlado de empresas piloto.
- Sem grandes refatorações ou novas funcionalidades durante a RC1.
- Modo piloto aumenta o volume de logs/telemetria.

### Modo piloto

- Build: `VITE_PILOT_MODE=true|false` (padrão da RC1: `true`).
- Runtime: botão **Modo Piloto** no dashboard operacional (`/admin/pilot-dashboard`) ou
  `localStorage.setItem('navaldocs.pilot_mode', 'false')`.

### Critérios de promoção para 1.0

1. Nenhum bloqueador P0.
2. Nenhum P1 aberto.
3. Estabilidade operacional elevada.
4. Fluxo completo funcionando ponta a ponta.
5. Isolamento entre tenants preservado.
6. Alta taxa de sucesso das operações.
7. Feedback positivo dos participantes do piloto.
